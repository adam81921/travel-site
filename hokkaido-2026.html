Trip Planning

行程規劃

🍼 親子環島遊 · 7天6夜定稿

帶快兩歲小朋友的環島路線：札幌 → 旭川 → 富良野 → 洞爺湖 → 小樽 → 札幌 → 機場。三大動物園（旭山、昭和新山熊牧場、圓山）＋ 花田、運河、湖景花火、機場樂園輪番上陣。最長拉車日是 D4 富良野→洞爺（約 3.5 小時），刻意排在午後讓小孩在車上睡。每日地圖為 OSRM 實際開車路線。

D1

抵達札幌 · 安頓休息

9/5（六）· 車程 55 分 · 宿 札幌
當天移動 · 機場 → 札幌

15:00 新千歲落地・領行李・辦租車 → 16:30 出發 → 自駕 55分 → 17:30 札幌 Check-in → 晚餐：札幌車站商場

景點介紹
🛬
新千歲機場（CTS）↗

北海道門戶。入境後辦租車（記得預約兒童安全座椅），藥妝補尿布、副食品再上路。

🍽
札幌車站商場 Stellar Place / Esta↗

札幌駅正上方的複合商城，晚餐選擇多到爆——拉麵共和國、迴轉壽司、洋食皆有，下雨天也不怕。 🚗 MAPCODE 9 522 804*81（JR塔東側立體停車場）

🏨 今晚住宿 · 札幌
待訂

抵達當晚先暫定札幌市區，方便隔天一早出發前往旭川。

D2

札幌 → 旭川 · 旭山動物園

9/6（日）· 車程 2h · 宿 OMO7 旭川
當天移動 · 札幌 → 旭川 → 旭山動物園

08:30 出發避塞車 → 自駕 2h（道央道）→ 10:30 旭川吃拉麵當早午餐 → 12:00 旭山動物園（玩到 16:30） → 17:30 回旭川 Check-in

景點介紹
🍜
旭川拉麵 · 梅光軒／山頭火本店↗

旭川名物醬油拉麵，梅光軒是當地代表、山頭火本店在旭川，鹽味豚骨清爽不油膩，小朋友也能接受。

🐧
旭山動物園↗ ⭐ 主菜

日本人氣第一動物園，以行動展示聞名——企鵝水中隧道、海豹圓柱水槽、北極熊近距離觀察。9 月夏季開到 17:15，先查好「もぐもぐ餵食時間」最精彩。 🚗 MAPCODE 79 357 858*27（正門停車場）

🥩
晚餐 · 成吉思汗大黑屋／回轉壽司なごやか亭

大黑屋是旭川烤羊肉名店，現烤現吃；なごやか亭是道產回轉壽司連鎖、CP 值極高，帶小孩也輕鬆。

🏨 今晚住宿 · 旭川
OMO7 旭川 by 星野集團↗

星野系城市觀光飯店，旭川車站旁、與 AEON 連通；OMO Base 公共空間寬敞，親子超便利。 🚗 MAPCODE 79 374 125*47

D3

旭川 → 美瑛 → 富良野

9/7（一）· 車程 1h10 · 宿 新富良野王子飯店
當天移動 · 美瑛 → 富良野

09:00 退房 → 40分 → 09:45 青池 → 5分 → 10:15 白鬚瀑布 → 30分 → 11:00 四季彩之丘（午餐+羊駝） → 14:00 Flower Land 上富良野 → 16:00 新富良野王子 Check-in → 17:00 森林精靈露台

景點介紹
💙
青い池（青池）↗

美瑛知名鈷藍色水池，枯立樹的倒影夢幻寧靜。步道平緩好推娃娃車，拍照 15 分鐘。 🚗 MAPCODE 349 569 603*11（停車場，限左轉進場）

💦
白鬚瀑布（白ひげの滝）

離青池 5 分鐘，從橋上看伏流水從岩壁噴出、與下方藍河共構奇景，停 5 分鐘順遊。 🚗 MAPCODE 796 182 516*00（白金公共停車場，徒步5分）

🦙
四季彩之丘↗

美瑛丘陵的彩色花毯，附設小動物牧場可近距離餵羊駝，是小孩最開心的一站。停 2.5 小時含午餐。 🚗 MAPCODE 349 701 216*03

🌷
Flower Land 上富良野↗

大花田＋拖拉機巴士遊園，小朋友超愛。9 月還有大波斯菊、向日葵盛開。 🚗 MAPCODE 349 518 415

🧚
森林精靈露台（Ningle Terrace）↗

新富良野王子腹地內的童話森林木屋商店街，傍晚點燈最美，散步順買手作小物。

🍛
唯我獨尊 富良野咖哩↗

富良野必吃名物咖哩，自製香腸搭咖哩飯，老店風味。

🏨 今晚住宿 · 富良野
新富良野王子大飯店↗

森林度假村，腹地內有 Ningle Terrace、Picnic Garden 與森林泳池，親子設施完整。 🚗 MAPCODE 919 553 393*85（飯店停車場，森林精靈露台共用）

D4

富良野 → 洞爺湖（最長拉車日）

9/8（二）· 車程 3h30 · 宿 乃之風 Resort
當天移動 · 富良野 → 洞爺湖

09:00 飯店早餐＋玩設施 → 10:30 退房・富良野起司工房 → 12:00 出發 → 中途夕張／苫小牧 SA 休息＋午餐 → 15:30 抵洞爺 Check-in → 16:00 泡湯 → 20:45 湖上花火

景點介紹
🧀
富良野起司工房↗

退房後順路，可看製程、做奶油／冰淇淋 DIY、現場吃冰。 🚗 MAPCODE 550 840 171*88

🚗
拉車策略

整趟最長一段（3.5h）。建議：富良野→夕張（1h，可吃哈密瓜）→苫小牧（再 1.5h，吃午餐）→洞爺（再 1h）。寶寶吃飽後上車剛好午睡。

♨️
洞爺湖溫泉

抵達後不安排額外行程，直接 Check-in 享受飯店泡湯與晚餐，把精神留給晚上花火。

🎆
洞爺湖 Long Run 花火大會↗

每年 4/28–10/31 每晚 20:45 起 20 分鐘湖上花火，湖景房在房內直接看，是 D4 最大亮點。

🏨 今晚住宿 · 洞爺湖
湖景 TOYA 乃之風渡假酒店↗

湖景房可在房內直接看 20:45 花火，新派和風溫泉飯店、頂樓有展望大浴場。 🚗 MAPCODE 321 519 540（官方公布）

D5

洞爺湖 → 小樽

9/9（三）· 車程 2h12 · 宿 Hotel Sonia 小樽
當天移動 · 洞爺湖 → 昭和新山 → 小樽

09:00 早餐 → 10:00 Sairo 展望台俯瞰洞爺湖 → 昭和新山熊牧場 → 12:00 出發 → 14:15 抵小樽 → 14:30 運河・北一硝子・音樂盒堂 → 17:00 LeTAO 本店・堺町通

景點介紹
🌋
Sairo 展望台↗

洞爺湖最佳俯瞰點，整片湖景＋中島＋羊蹄山一覽無遺。 🚗 MAPCODE 321 726 732*66（停車場）

🐻
昭和新山熊牧場↗

近距離看蝦夷棕熊，買餅乾餵熊體驗。小孩看熊舉手討食物會很興奮。 🚗 MAPCODE 321 433 323*36（園區共用停車場）

🚢
小樽運河

石造倉庫＋煤氣燈的懷舊運河，下午散步、傍晚點燈都很美。沿岸平坦好推娃娃車。 🚗 MAPCODE 493 690 715*11（小樽市觀光駐車場；住 Sonia 直接停飯店步行即可）

🔮
北一硝子三號館↗ · 音樂盒堂本館↗

北一硝子是小樽玻璃工藝代表；音樂盒堂滿屋八音盒＋蒸氣鐘，小孩看得入迷。

🍰
LeTAO 本店↗

雙層起司蛋糕創始店，二樓 Café 可內用看堺町通。買新鮮現做的回飯店當宵夜。

🍣
政壽司本店↗ / 運河旁海鮮

小樽壽司通名店，新鮮道產海鮮。晚餐悠閒吃完散步運河。

🏨 今晚住宿 · 小樽
Hotel Sonia Otaru↗

就在小樽運河正旁邊，運河景房可直接看夜晚點燈，散步去堺町通也只要幾分鐘。 🚗 MAPCODE 493 690 528*27（飯店後方自家停車場 37 台，先到先停）

※ 7/27 前可免費取消
D6

小樽 → 札幌親子日

9/10（四）· 車程 50 分 · 宿 札幌
當天移動 · 小樽 → 札幌

09:30 退房・悠閒早餐 → 10:30 出發 → 11:30 抵札幌放行李 → 12:00 午餐 → 13:30 圓山動物園 OR AOAO 水族館 → 16:30 白色戀人公園 → 晚餐

景點介紹
🥩
成吉思汗 達磨 本店↗ / 麵屋 彩未↗

達磨是札幌烤羊肉始祖，老店風味；彩未是札幌味噌拉麵代表，午餐二選一。

🐘
圓山動物園↗

札幌市區動物園，北極熊館有水底隧道、紅貓熊近距離觀察，戶外步道適合放電。 🚗 MAPCODE 9 456 749*63（圓山公園第1停車場）

🐠
AOAO SAPPORO↗（雨備）

2023 新開幕的都市型水族館，在 moyuk SAPPORO 4–6 樓。企鵝展演、水母牆超夢幻。下雨或省時可改這裡。 🚗 MAPCODE 9 492 565*45（moyuk大樓，停周邊路外停車場）

🍫
白色戀人公園↗

名產觀光工廠＋歐風城堡＋園區小火車＋餅乾 DIY＋室內遊戲區，小朋友殺時間天堂。 🚗 MAPCODE 9 603 300*11

🍺
札幌啤酒園↗ / 狸小路

啤酒園百年紅磚建築裡吃成吉思汗烤肉＋現釀生啤；狸小路就是逛街吃宵夜的鬧區。 🚗 MAPCODE 9 554 261*77（啤酒園，園內有停車場）

🏨 今晚住宿 · 札幌
待訂

回程前一晚，可續住札幌市區，或改機場周邊（新千歲機場王子）讓隔天最省力。

D7

機場樂園 → 回程

9/11（五）· 車程 55 分 · 回家
當天移動 · 札幌 → 機場

早上採買（大丸／AEON） → 11:30 抵機場周邊還車（預留 1h 程序） → 12:30 機場午餐＋逛 → 14:15 登機 → 16:15 BR115 起飛 → 19:15 抵桃園

🚗 MAPCODE 113 742 185*47（機場航廈；還車請以租車公司提供的營業所 mapcode 為準）
機場樂園 · 候機放電
✈️
大空博物館（大空ミュージアム）↗

國內線 3F 免費航空主題小博物館：兒童遊戲區、飛行員／空服員制服拍照、付費飛行模擬器。（原哆啦A夢空中樂園已於 2025/7 結束營業）

🎀
Hello Kitty Happy Flight↗

機場 3F，凱蒂貓主題環遊世界體驗區，女兒控必訪。

🍫
Royce' 巧克力工房↗

機場 2F，現場看製程、買最新鮮巧克力。生巧克力買回台灣當伴手禮。

🍜
機場拉麵道場 / 海鮮

4F 拉麵道場集結道內 10 家名店；2F 美食街海鮮丼、湯咖哩齊全，吃個飽再上機。

👶 親子小提醒

每天一個主要重點＋午睡緩衝，不排滿
只有札幌／旭川兩基地；長程拉車排午後，讓小孩車上睡
9 月初 15–22°C，早晚涼，洋蔥式穿搭
娃娃車可用，動物園／花田有坡道，揹巾更靈活

🚗 交通建議

全程自駕：美瑛、Northern Horse Park 大眾運輸不便
租車務必同時預約兒童安全座椅
車用導航輸入各景點的 🚗 MAPCODE 最快最準（已標在每個景點下方，長按數字可複製）
走道央道＋一般道，雪季外路況單純好開

🍁 北海道 9 月

初秋舒適 15–22°C，美瑛丘陵景色正好
薰衣草季已過，富田農場仍有花田＋哈密瓜
當季海鮮：毛蟹、海膽、秋鮭
出發前 1–2 個月再訂房、確認景點營業
